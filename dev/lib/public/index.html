Public API

Construct a scheme

NineFourths.BilinearScheme — Type
BilinearScheme

Abstract type for finite bilinear matrix multiplication rules.

Index a rule as scheme[term, leg, coordinate] to access a weight of a rank-one product. Legs 1 and 2 give the left and right linear forms. Leg 3 gives the output weights. A ShpilkaScheme returns a deferred coefficient.

See also multiplication_scheme, verify_scheme, multiply.

source
NineFourths.multiplication_scheme — Function
multiplication_scheme(target_exponent=5//2)::BilinearScheme

Construct a reusable bilinear matrix multiplication rule for a target exponent.

Pass a finite integer or exact rational strictly greater than 9//4, as required by Theorem 1.2 of Shpilka's exposition. The rule stores the finite substitution program, including tensor powers and derivation loops, in symbolic form. The block side can exceed the runtime's indexing limits.

Use verify_scheme to check its construction and exponent bound, and multiply to request a product. Indexing the rule returns a deferred contraction for the requested coefficient.

Examples

julia> using NineFourths

julia> scheme = multiplication_scheme(5//2);

julia> scheme isa BilinearScheme
true

julia> report = verify_scheme(scheme);

julia> (report.identity, report.exponent <= 5//2)
(:symbolic_restriction, true)

Verify and apply a scheme

NineFourths.verify_scheme — Function
verify_scheme(scheme::ExplicitScheme; field=nothing)::VerificationReport

Check an explicit rule on all pairs of matrix units in exact arithmetic.

Infer the field from the coefficients with field=nothing. Supply an exact scalar type, a representative element, or a callable parent such as Nemo.GF(5) to select it explicitly. A verified rule with block side at least two gives an exponent bound from its block side and product count.

See also BilinearScheme, multiplication_scheme.

Examples

julia> using NineFourths

julia> scheme = BilinearScheme([2;;], [3;;], [1//6;;]);

julia> verify_scheme(scheme).identity
:exact_coefficients

julia> verify_scheme(BilinearScheme([2;;], [3;;], [1//5;;])).valid
false
source
verify_scheme(scheme::LoweredScheme; max_terms=1_000_000)::VerificationReport

Check the matrix multiplication tensor from the exact coefficients of a lowered rule.

max_terms bounds the number of table entries and potential rank summands. Each coefficient can require additional work to contract its restriction row with the seed. If the bound prevents enumeration, the report has identity == :unchecked.

source
verify_scheme(scheme::ShpilkaScheme)::VerificationReport

Check the executable construction and exponent certificate for a Shpilka rule.

Verify the derivation recipe and the symbolic copy, degree, and rank bounds from §6 of Shpilka's exposition. The resulting identity status is :symbolic_restriction. The certificate relies on the algebraic primitives of the compiler and seed builder.

See also multiplication_scheme.

NineFourths.multiply — Function
multiply(A, B, scheme; <keyword arguments>)::Matrix

Multiply an m×k matrix by a k×n matrix using a bilinear scheme.

For positive dimensions the default requires at least one bilinear scheme layer. The product uses implicit zero padding along each axis and conventional multiplication at the leaves. A zero dimension determines an empty or zero matrix directly.

With the default field=nothing, built-in Julia integer inputs produce Matrix{BigInt}. Built-in rational inputs, including mixtures with built-in integers, produce Matrix{Rational{BigInt}}. Other inputs use their common scalar domain. All results are dense Julia matrices.

Arguments

  • fallback=:error requires the scheme. Use :classical to permit a conventional product when the scheme exceeds its execution bounds or a coefficient cannot act in the selected domain.
  • field=nothing infers the scalar domain from the input. Supply a parent callable as field(0) and field(1), a scalar type with identities, or a representative element to select it explicitly.
  • max_coefficient_visits::Integer=10_000_000 bounds coefficient reads across the recursive product.
  • max_workspace_entries::Integer=10_000_000 bounds live dense entries, including normalized inputs and the result. It also applies to a conventional product.

Both budgets must be nonnegative.

See also BilinearScheme, multiplication_scheme, and verify_scheme.

Examples

julia> using NineFourths

julia> scalar_rule = BilinearScheme([1;;], [1;;], [1;;]);

julia> C = multiply([1 2 3; 4 5 6], [1 0; 0 1; 1 1], scalar_rule);

julia> (eltype(C), C == [4 5; 10 11])
(BigInt, true)

julia> paper_rule = multiplication_scheme();

julia> C = multiply([2;;], [3;;], paper_rule; fallback=:classical, field=Float32);

julia> (eltype(C), only(C) == 6)
(Float32, true)

Implementation

A and B can be Julia AbstractMatrix values, Nemo matrices, or other containers with integer dimensions from size(M) and scalar entries from M[i, j]. axes(M) supplies the index ranges and defaults to one-based axes. Field inference uses eltype(M) and the entries.

A custom scheme supplies NineFourths.execution_dimensions(scheme, max_side, max_rank), returning a positive (side, rank) pair within the limits or nothing. NineFourths.scheme_coefficient(scheme, term, leg, coordinate) supplies weights for one-based term and column-major block indices. Legs 1 and 2 address the input forms, and leg 3 addresses the output weights. NineFourths.block_side(scheme) supplies the block side for diagnostics. The Shpilka scheme can report a symbolic WitnessSide.
