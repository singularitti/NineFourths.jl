Parameters and derivation

The target exponent determines integer bounds for a finite sequence of tensor restrictions. The derivation records the operations that the witness compiler will apply.

Parameter selection

NineFourths._OPENAI_EXPONENT_BOUND — Constant
_OPENAI_EXPONENT_BOUND::Rational{BigInt}

The exact reference exponent 9//4 that the construction approaches.

source
NineFourths.ScaledPowerOfTwo — Type
ScaledPowerOfTwo(coefficient, exponent)

Represent the exact product coefficient * 2^exponent in factored form.

Both fields are stored as BigInt. This representation keeps large powers from having to be expanded when only the construction parameters are needed.

source
NineFourths.ShpilkaParameters — Type
ShpilkaParameters(target)

Choose the exact parameters in Shpilka's proof of Theorem 1.2.

target must have a finite exact rational value above OpenAI's 9//4 bound. The constructor accepts Julia integers and rationals and Nemo values supported by rational_result, such as Nemo.QQFieldElem. A nonfinite rational target or one at or below 9//4 raises DomainError.

target and epsilon are stored as Rational{BigInt}. epsilon is the gap between the target and 9//4, capped at one. q = ceil(16 / epsilon^2) and step_bound = q * (2q^2 + 7q) are stored as BigInt. The latter bounds the number of non-baseline derivation entries. a = q * 2^q is the final diagonal coordinate and length_bound = 4a bounds all lengths in the derivation. These two values are BigInt or, for large powers, ScaledPowerOfTwo.

show(io::IO, value::ScaledPowerOfTwo)

NineFourths._scaled_power_of_two — Method
_scaled_power_of_two(coefficient::Integer, exponent::Integer)

Scale an integer coefficient by a power of two.

Return a shifted BigInt for ordinary shifts or a ScaledPowerOfTwo for large exponents. Construction parameters use nonnegative exponents, for which both representations give the exact product.

Derivation steps

NineFourths.DerivationNode — Type
DerivationNode(a, b, value, kind, predecessors)

Represent one lower bound and its justification in a materialized derivation.

a and b are BigInt polynomial lengths. value is an exact Rational{BigInt} lower bound on F(a, b), the paper's supremum of witness rates for the balanced polynomial tensor at those lengths. kind is one of :baseline, :restriction, :symmetry, :midpoint, or :tripling.

predecessors stores Int indices into earlier entries of the same derivation. A baseline has no predecessors, a midpoint has two in increasing column order, and other rules have one.

source
NineFourths.ShpilkaDerivation — Type
ShpilkaDerivation(parameters::ShpilkaParameters)

Store the exact parameters for the derivation in Shpilka's Theorem 1.2.

The derivation starts with the baseline at (q, q) and applies Lemma 6.5 successively at step lengths 1, 2, 4, …, 2^(q-1). See materialize_derivation for the resulting list of proof entries. Exposition of OpenAI’s Matrix Multiplication in Exponent 9/4 (and an explicit algorithm).

source
NineFourths._extend_row! — Method
_extend_row!(nodes, start, distance, depth)

Extend a derivation along one row and return the index at the requested column.

Given nodes[start] at (a,b), reach (a,b + distance) using Lemma 6.3 and Claim 6.4. distance lies in 1:a+2b, and depth is the nonnegative limit on the number of midpoint steps. nodes is a one-based, appendable collection of DerivationNode entries. Build the chain of midpoint targets, then append its steps in dependency order, starting from an endpoint or a restriction of the original bound.

source
NineFourths._push_derivation_node! — Method
_push_derivation_node!(nodes, a, b, value, kind, predecessors)

Append a DerivationNode and return its one-based index.

nodes supports push! and length, as a Vector{DerivationNode} does. Supply integer lengths, an exact rational bound, a rule symbol, and a tuple of predecessor indices convertible to Int.

source
NineFourths.materialize_derivation — Method
materialize_derivation(derivation)::Vector{DerivationNode}

Generate the proof entries in dependency order with exact dyadic values. Use a ShpilkaDerivation or another description exposing a positive Integer derivation.parameters.q. This enumerates the full derivation, including intermediate entries of the row extensions. For targets close to 9//4 it can require substantial resources.
