Field arithmetic and specialization

The executor infers or accepts a scalar field, specializes roots of unity and interpolation for that field, and converts the result back to the field of the inputs.

Roots of unity in the input field

NineFourths.FieldPhaseSum — Type
FieldPhaseSum(terms, zero_value)

Store a normalized phase dictionary and the additive identity of its working scalar domain. This representation keeps arithmetic on the weights in that domain while formal roots of unity supply the phases. Distinct phases can still satisfy cyclotomic relations.

source
NineFourths._FieldPhaseTerms — Type
_FieldPhaseTerms

Dictionary from normalized Rational{BigInt} phases to weights in the working scalar domain. Phases use the half-turn convention of PhaseSum.

source
NineFourths._add_field_phase! — Method
_add_field_phase!(terms, phase, weight, zero_value)

Add a weight to a mutable _FieldPhaseTerms dictionary. Normalize the rational phase to [0, 1/2) and adjust the weight's sign before adding. Remove a term when its weight equals the field's zero_value. Return nothing.

source
NineFourths._constant_phase_sign — Method
_constant_phase_sign(phase, factors)::Int

Return the coefficient in -1:1 obtained by projecting exp(2πim * phase) onto the constant term. Tensor the power-basis projections of the prime-power cyclotomic rings for the reduced denominator of phase. The factors cache maps BigInt root orders to the results of _squarefree_prime_factors.

A primitive root of order p^k has constant coefficient zero for k > 1. For k = 1, the coefficient is -1 at exponent p - 1. For a phase n/d, the Chinese remainder theorem gives that exponent precisely when n ≡ -(d ÷ p) mod p.

NineFourths._field_add — Function
_field_add(left, right)

Add two working values in the same scalar domain. Scalars add directly. When either operand is a FieldPhaseSum, treat each scalar as a constant term and combine weights at equal phases.

_field_apply(coefficient, value)

NineFourths._field_iszero — Function
_field_iszero(value, zero_value)::Bool

Compare a scalar with its field's additive identity. For a FieldPhaseSum, test whether its dictionary is empty. A nonempty dictionary can still vanish through cancellation between different phases.

source
NineFourths._field_mul — Function
_field_mul(left, right)

Multiply two working values in the same scalar domain. Scalars multiply directly, a scalar with a FieldPhaseSum scales each phase weight, and two phase sums combine all phase pairs by addition of phases and multiplication of weights.

source
NineFourths._field_phase_coefficient — Function
_field_phase_coefficient(embed, coefficient, zero_value=embed(big(0) // 1))

Embed a PhaseSum coefficient's Rational{BigInt} weights using the callable embed. Keep the original phases and drop terms whose embedded weights equal zero_value. The result is a working scalar or a FieldPhaseSum.

source
NineFourths._finish_field_phases — Method
_finish_field_phases(terms, zero_value)

Finish a normalized phase sum. Return the supplied zero for an empty dictionary, the scalar weight for a lone constant term, or a FieldPhaseSum for other dictionaries.

source
NineFourths._project_complex_value — Method
_project_complex_value(value)

Project a FieldPhaseSum with Julia Complex weights into its complex scalar domain. Here the formal fourth root acts as the native imaginary unit. If f is the constant-term projection, f(z) + im*f(-im*z) commutes with multiplication by im and fixes Gaussian scalars.

source
NineFourths._project_field_value — Function
_project_field_value(value)

Return an ordinary working scalar unchanged. For a FieldPhaseSum, apply the integer-linear constant-term projection and return its scalar value. This projection fixes scalar terms and selects a component from a general symbolic sum.

source
NineFourths._squarefree_prime_factors — Method
_squarefree_prime_factors(order)

Factor a positive integer order with Nemo. Return its prime divisors as a Vector{BigInt} when it is squarefree, or nothing when a factor repeats. The order one has an empty factor list.
