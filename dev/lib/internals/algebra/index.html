Scalars and tensor maps

Construction coefficients can depend on a formal parameter and a root of unity. Tensor restrictions act on each leg via sparse columns. These entries describe the scalar operations, map indexing, composition, and tensor products.

NineFourths.PhaseSum — Type
PhaseSum(terms)

Represent an exact cyclotomic expression as a sparse sum of terms weight * exp(2πim * phase). The dictionary terms maps Rational{BigInt} phases, measured in turns, to nonzero weights of the same type. Phases lie in [0, 1/2), with each half turn absorbed into the sign of its weight.

Use root_of_unity or phase_monomial to construct normalized terms from arbitrary rational phases. Distinct keys can still satisfy cyclotomic relations. Equality tests the algebraic value of the sum.

NineFourths.phase_trace — Method
phase_trace(phase, traces)::Rational{BigInt}

Compute the normalized field trace of exp(2πim * phase). For the reduced denominator d of the rational phase, the trace is μ(d) / φ(d), where μ is the Möbius function and φ is Euler's totient. This value also applies when the root belongs to a larger cyclotomic field. Cache traces in traces by root order.

Tensor restriction maps

NineFourths.LegMap — Type
LegMap(in_dim, out_dim, entry, support=nothing, selection=nothing)

Represent a single leg of a tensor restriction from in_dim source variables to out_dim target variables.

Each column gives the substitution of one source variable as a linear combination of target variables. Dimensions are stored as BigInt and must be positive, or the constructor throws ArgumentError.

Each callback receives one-based BigInt indices.

  • entry(row, col) returns the exact coefficient at that target row and source column, for example an Int, Rational{BigInt}, or PhaseSum.
  • support(row) yields (column, weight) contributions whose sum at each column equals entry(row, col). A source column may occur more than once.
  • selection(row) returns the source column if it is the only nonzero entry and has weight one. It returns zero for an all-zero row. Supply this callback only if all rows satisfy this contract.

support and selection may be nothing. See also row_entries and selection_map.

NineFourths._compose_maps — Method
_compose_maps(a, b)::LegMap

Compose leg maps by applying a first and b second.

The operands are usually LegMaps. They expose in_dim, out_dim, and selection. A general composition uses row_entries and indexes a. The returned row contributions multiply and sum through the intermediate leg, which means repeated source columns are possible. Mismatched intermediate legs raise DimensionMismatch.

source
NineFourths._product_maps — Method
_product_maps(a, b)::LegMap

Tensor two leg maps with the coordinates of a varying fastest.

The operands are usually LegMaps. They expose in_dim, out_dim, and selection, and a general product uses row_entries and indexed coefficients. A coordinate pair (i, j) packs to i + d * (j - 1), where d is the first factor's source or target dimension as appropriate. Each row contribution multiplies weights from one source coordinate in each factor.

NineFourths.mm_product — Method
mm_product(sides)::TensorRestriction

Identify a tensor product of square matrix multiplication tensors with one square matrix multiplication tensor whose side is prod(sides).

sides lists the positive integer factor sides in source order. The source coordinate packs each factor's row and column together, with the first factor varying fastest. The target stores the assembled row and column in Julia column-major order. An empty list gives the side-one identity and a nonpositive side raises ArgumentError. See also mm_split.

source
NineFourths.mm_split — Method
mm_split(source_side::Integer, sides)::TensorRestriction

Crop a square matrix multiplication tensor and split it into the specified factors.

sides lists positive integer sides in target order. Keep the first prod(sides) indices in each matrix dimension, then apply the inverse of mm_product(sides) to those coordinates. If the product exceeds source_side, throw DimensionMismatch. A nonpositive factor side raises ArgumentError.

source
NineFourths.permute_factors — Method
permute_factors(dimensions, order)::TensorRestriction

Reindex a tensor product so its factors occur in the given order.

dimensions lists the positive leg-dimension triples in source order. The order iterable lists the one-based source factor indices in target order. For example, (3, 1, 2) moves the third source factor first. Both layouts use first-factor-fastest coordinates. An invalid permutation raises ArgumentError.

NineFourths.unit_to_mm — Method
unit_to_mm(n::Integer)::TensorRestriction

Construct the classical rank decomposition of a catalyst matrix tensor of side n.

Each leg has n^3 source columns encoding (i,k,j) with i varying fastest. The n^2 target rows encode (i,k), (k,j), or (i,j) on the three legs in column-major order. All contributions have weight one. A nonpositive side raises DomainError.
